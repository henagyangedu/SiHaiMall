# 贡献者协议

感谢你愿意为四海商城 SihaiMall 贡献代码、文档或译文。

本项目对非商业用途免费，同时向商业使用者提供收费的商业授权，收入用于项目的维护和开发（见[授权说明](授权说明.md)）。为了让项目作者能把大家贡献的内容一并纳入这两种授权方式，需要你在提交贡献前同意下面的条款。

> 这是一份常见写法的简明协议，尚未经过律师审定。项目正式接受外部贡献前，建议由律师确认。

## 条款

1. **你保留版权。** 你贡献的内容，版权仍然归你。

2. **你授予的许可。** 你授予项目作者一项永久的、全球范围的、非独占的、免费的、不可撤销的许可，允许项目作者复制、修改、发布、分发你贡献的内容，并以任何许可证（包括本项目的公开许可证和收费的商业授权）向他人再授权。

3. **专利。** 如果你贡献的内容涉及你拥有或有权许可的专利，你同样按上一条的范围授予专利许可。

4. **你的保证。** 你确认：
   - 贡献的内容是你自己写的，或者你有权按本协议提交；
   - 如果是在工作中完成的，你已经得到雇主的许可，或者雇主对它没有权利主张；
   - 内容里包含别人的代码时，你已经在提交说明里写清楚来源和它的许可证。

5. **没有义务。** 项目作者没有义务采纳你的贡献；你也没有义务为贡献的内容提供支持。

6. **没有报酬。** 除非另有书面约定，你不会因贡献而获得报酬，也不会分享商业授权的收入。

## 怎么表示同意

在 Pull Request 的说明里勾选“我已阅读并同意贡献者协议”。没有勾选的 Pull Request 不会被合并。
